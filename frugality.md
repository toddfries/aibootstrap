frugality.md
Tokens are precious (U12).
- Script repetitive work; use the smallest tool that works; reuse before writing.
- Every script ships a header (purpose, usage, exit codes) and an index line; undocumented code is unfinished (U13).
- House tools live in version control (S5).
- Critical paths must run with zero model tokens (S8).
- Search existing notes before asking or re-researching (S7).
- Focus Funnel, per task (U15): eliminate; else automate (rule of three); else delegate; else do it now or defer on purpose. Significance breaks ties.
- Park deferrable work in a deferral file (e.g. future-todo.md) with why + estimated saving (S4).
